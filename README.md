# شاشتي

صفحة للتلفاز: الساعة والتاريخ الهجري، ومباراة الفريق القادمة وترتيبه في الدوري، وآخر الأخبار العاجلة، وفيلم مقترح، وشريط تطبيقات.

## كيف تعمل

- `fetch.py` يجمع البيانات في ملف `data/tv.json`. GitHub Actions يشغّله كل ساعة (`.github/workflows/update.yml`).
- `index.html` هي الصفحة. تقرأ `data/tv.json` وتحدّث نفسها كل ١٠ دقائق.
- GitHub Pages ينشر الصفحة على رابط باسمك.

## الإعدادات (`config.json`)

| المفتاح | المعنى |
|---|---|
| `city`, `country`, `city_ar` | مدينة مواقيت الصلاة |
| `timezone` | توقيت الساعة في الصفحة، مثل `Asia/Qatar` |
| `prayer_method` | طريقة الحساب في Aladhan (`10` = قطر) |
| `team_id`, `team_ar` | الفريق في TheSportsDB (`133667` = ميلان) |
| `league_id` | دوري الفريق (`4332` = الدوري الإيطالي) |
| `news_rss`, `news_count` | مصدر الأخبار وعددها |

بعد أي تغيير في `config.json` وحفظه على GitHub، يعمل التحديث وحده.

## التجربة على جهازك

```
python fetch.py
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المصادر

- الأخبار: موقع الجزيرة نت (RSS).
- المباريات والترتيب: TheSportsDB (المفتاح المجاني). الترتيب يُحسب من نتائج جولات الموسم: ٣ نقاط للفوز، ونقطة للتعادل.
- التاريخ الهجري: Aladhan.
- الفيلم المقترح: قائمة أفضل ٢٥٠ فيلماً تُحسب كل أسبوع (`movies.py`) من ملفات IMDb المجانية للاستخدام الشخصي غير التجاري
  (Information courtesy of IMDb (https://www.imdb.com). Used with permission.)، والشرح بالعربي من ويكيبيديا عبر Wikidata.
